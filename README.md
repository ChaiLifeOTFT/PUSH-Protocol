## What is P.U.S.H.?

P.U.S.H. is a protocol for how AI agents can propagate capabilities to other AI agents without human intervention.

**The problem:** Every time you add a new AI node (local Ollama model, cloud API, phone-based agent), you have to manually teach it your system's conventions, coordination patterns, and self-governance rules.

**The solution:** A structured format for encoding "how to do X" so that one agent can teach another — including a coordination grammar that lets heterogeneous AI nodes communicate intent, not just data.
